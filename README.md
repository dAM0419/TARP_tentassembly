# TARP — Tent Assembly: Rigging and Pitching

**천막 지지대 · 천막 노끈 · 말뚝 · 방수포** 네 가지 재료만으로 원하는 천막을 직접 조립하는 마인크래프트 모드입니다.
웨지·벨·피라미드·티피·베두인 천막부터 나무나 벽에 말뚝을 박아 만드는 간이 차양까지, 천막 종류별 전용 코드 없이 재료끼리 맞물리는 규칙만으로 만들어집니다.

| 항목 | 값 |
| --- | --- |
| Minecraft | 1.21.1 |
| 모드 로더 | NeoForge 21.1.252 이상 |
| Java | 21 |
| 모드 ID | `tarp` |

| 선택 연동 | Farmer's Delight (지푸라기로 노끈 제작) |

## 설계 원칙

- **원리만 만듭니다.** 천막의 모양은 정해 두지 않습니다. 재료를 어떻게 세우고 묶느냐에 따라 저절로 결정됩니다.
- **재료 하나에 역할 하나.** 지지대는 밀어서 버티고, 노끈은 당기고, 말뚝은 고정하고, 방수포는 막이 됩니다.
- **현실감은 낭만까지만.** 쓰러짐·유격·절개선은 있지만, 블록 재질이나 힘의 크기처럼 머리 아픈 계산은 넣지 않았습니다.

## 재료

| 재료 | 하는 일 | 제작 |
| --- | --- | --- |
| **천막 지지대** | 골조. 한 아이템으로 수직·수평·대각 어디로든 세웁니다. 길이 2칸마다 1개를 씁니다. | 막대기 3개 세로 → 3개 |
| **천막 노끈** | 말뚝과 함께 벽·나무 사이에 용마루줄을 만들거나, 지지대를 당김줄로 붙잡습니다. 길이(올림)만큼 씁니다. | 실·밀·지푸라기(Farmer's Delight) 3개 세로 → 3개 |
| **말뚝** | 블록의 어느 면에나 박히는 고정점입니다. | 막대기 + 부싯돌 → 4개 |
| **방수포 (소·중·대, 16색)** | 골조 위에 한 장으로 덮여 천막의 안과 밖을 나눕니다. | 아래 참고 |
| **잎 덮개** | 방수포 대용입니다. 하루가 지나면 말라서 사라집니다. | 나뭇잎 블록 2×2 (아무 나뭇잎) |
| **천막 키트** | 완성된 천막을 재료째 담아 다른 곳에 다시 칩니다. | 가죽 2×2 + 대각선 아래 칸에 천막 노끈 |

### 방수포 제작

- **소형**: 같은 색 양털 2×2 + 대각선 아래 칸에 벌집 조각 (밀랍 처리)
- **중형**: 소형 / 실 / 소형 (세로 또는 가로, 같은 색끼리)
- **대형**: 중형 / 실 / 중형 (세로 또는 가로, 같은 색끼리)
- **염색**: 방수포 + 염료(모양 무관) → 같은 크기의 그 색 방수포

모든 제작법은 데이터 레시피라 JEI에서 볼 수 있습니다.

## 사용법

### 지지대
1. 지지대를 들고 시작점을 우클릭합니다.
2. 끝점을 우클릭합니다. 다른 점을 겨누지 않으면 수직으로 늘어나며, 마우스 휠로 ½칸씩 길이를 바꿉니다.
3. 끝점은 기존 지지대 끝점, 지지대 위의 ½칸 지점, 말뚝 머리, 블록 면 가운데에 스냅됩니다.

미리보기 색은 안정성 예측입니다. **초록**은 혼자 섬, **노랑**은 기대야 섬, **빨강**은 쓰러짐입니다. 웅크리고 우클릭하면 선택을 취소합니다.

### 안정성
- 수직 지지대는 블록 윗면에 놓이면 혼자 섭니다.
- 수평 지지대는 양 끝이 모두 받쳐져야 합니다.
- 대각 지지대는 발이 받쳐지고, 꼭대기에 걸리는 방향들 사이에 180° 이상 빈 각도가 없어야 섭니다.
- 노끈 당김줄은 말뚝 쪽으로 당기는 방향으로 셉니다.
- 아래를 부수면 위 조각이 떨어지고, 구조가 이상하면 즉시 아이템으로 쓰러집니다.

### 노끈
묶는 점(말뚝 머리, 지지대 끝점) 두 개를 차례로 우클릭해 잇습니다. 끝점에서 이어서 계속 연결할 수 있습니다.
설치된 노끈은 칸마다 얇은 충돌 판정을 가집니다. 노끈을 부수면 **그 한 가닥만** 걷히고, 길이만큼 노끈이 떨어집니다.

### 방수포
1. 방수포를 들고 묶는 점을 차례로 우클릭합니다. 그 점들이 천막의 바닥 둘레가 됩니다.
2. 클릭할 때마다 반투명 투영이 나오고, 천의 넓이, 필요한 크기, 막힌 칸, 입구 가능 여부가 표시됩니다.
3. 첫 점을 다시 우클릭하면 한 번에 설치됩니다.

티피처럼 둘레 점이 많을 때는 골조를 웅크리고 클릭하면 주변 말뚝으로 둘레를 자동 제안합니다.
천은 골조(지지대·노끈) 바깥을 덮고, 밑단은 땅에서 유격만큼 떠 있습니다. 가위로 걷으면 방수포와 노끈이 돌아옵니다.

### 입구
- **지정**: 빈손으로 웅크리고 천을 우클릭해 변을 고르고, 한 번 더 누르면 확정됩니다. x 또는 z 방향 변만 고를 수 있고, 위치는 변의 가운데로 자동 정렬됩니다.
- **높이**: 항상 2칸입니다.
- **폭**: 변의 칸 수가 1·2면 변 전체, 짝수면 2칸, 3이면 1칸, 5 이상 홀수면 3칸입니다.
- **여닫기**: 빈손 우클릭으로 엽니다. 열면 위로 말린 두루마리가 되고, 양옆 절개선은 항상 보입니다.

### 천막 키트
- **담기**: 빈 키트를 들고 친 천막의 천을 **웅크리고 우클릭**하면 천막을 담습니다.
- **위치 고정**: 담긴 키트를 들면 천막 전체가 투영되어 시선을 따라다닙니다. Q/E로 90°씩 돌리고, 우클릭으로 위치를 고정합니다.
- **설치**: 지지대 → 말뚝 → 노끈 → 방수포 순서로 부품을 우클릭하면 저장된 그대로 설치되고, 입구도 살아납니다.

## 설정

모드 목록 → TARP → 설정, 또는 `config/tarp-common.toml`에서 바꿀 수 있습니다.

| 키 | 기본값 | 설명 |
| --- | --- | --- |
| `kit.instantPitch` | `false` | 켜면 키트 위치를 고정하는 순간 천막 전체가 한 번에 설치됩니다. |

## 빌드

```bash
./gradlew build                 # Windows: gradlew.bat build
./gradlew runGameTestServer     # 월드 동작 자동 시험 (GameTest)
```

결과물은 `build/libs/tarp-<버전>.jar`에 생깁니다. Gradle이 JDK 21을 자동으로 받습니다.

### 소스 구조

| 패키지 | 내용 |
| --- | --- |
| `com.tarp.core` | 마인크래프트와 무관한 순수 계산: 칸 래스터, 쓰러짐 판정, 막 모양(3차원 볼록 껍질), 입구 (JUnit 대상) |
| `com.tarp.world` | 저장(`TarpData`), 서버 규칙(`TarpService`), 월드와 계산 연결(`Planner`), 천막 키트(`Kit`) |
| `com.tarp.content` | 블록·아이템·제작법. 지지대·노끈·천이 차지하는 칸은 보이지 않는 블록 + 블록 엔티티 |
| `com.tarp.client` | 도구 조작, 스냅, 투영, 방수포·지지대·노끈 렌더링 |

## 패치 내역

### 0.4.9
- 지지대를 설치할 때 행동바에 개수·길이 안내가 보이지 않던 문제를 고쳤습니다. 안내를 다시 매 틱 띄웁니다.

### 0.4.8
- 용마루줄을 덮느라 생긴 먼 천 꼭짓점으로 밑단 고리를 긋던 문제를 고쳤습니다. 이 고리가 천을 뚫고 보였습니다. 이제 고리는 0.15칸 안의 모서리까지만 잇습니다.
- 노끈 위로 덮이는 천에 0.015칸 여유를 더했고, 땅 말뚝 쪽 밑단을 조금 올렸습니다.

### 0.4.7
- 천이 노끈·지지대를 뚫던 문제를 근본적으로 고쳤습니다. "밑단보다 낮은 골조는 덮지 않는다"는 판정을 골조 중심이 아니라 겉면 기준으로 바꿔, 천과 겹치는 골조는 모두 천 아래로 들어갑니다.
- **노끈이 물리적인 공간을 차지합니다.** 지나는 칸마다 보이지 않는 노끈 블록이 생기고, 부수면 노끈 한 가닥만 회수됩니다. 천 아래 노끈 칸은 천처럼 빛과 비를 막습니다.

### 0.4.6
- 지지대 높이를 바꿀 때 행동바 안내가 늦게 바뀌던 문제를 고쳤습니다. 다른 모드의 행동바 메시지에도 안내가 밀리고 있었습니다.
- 벽·나무 말뚝을 부술 때 걸린 노끈을 못 찾던 문제와, 말뚝 목 매듭이 잠시 남던 문제를 고쳤습니다.
- 0.4.5의 처지는 천 시험을 뺐습니다.

### 0.4.5
- **말뚝을 깊이 박습니다.** 머리 높이가 1/2칸에서 3/16칸으로 내려가고, 모델과 충돌 상자도 낮아졌습니다.
- 땅 가까이 묶은 점의 밑단을 바닥 + 유격 기준으로 바꿔, 말뚝에 묶은 천이 붕 뜨지 않습니다.

### 0.4.4
- 방수포 색을 살짝 바랜 톤으로 바꿨습니다. 설치된 천과 아이콘 48장이 같은 색입니다.
- 천막 키트 아이콘을 가죽 가방 + 황동 버클로, 소형·대형 방수포 아이콘의 두께를 다듬었습니다.

### 0.4.2 – 0.4.3
- 설치된 천막에 노끈을 감은 띠를 그립니다. 노끈이 걸린 지지대 끝, 지지대끼리 만나는 끝, 말뚝 목에 생기며, 겉모양만 바뀝니다.
- 방수포·노끈·지지대·말뚝 아이콘을 새로 그렸습니다.

### 0.4.0
- **방수포를 16색 × 3크기의 개별 아이템으로 나눴습니다.** 옛 방수포는 인벤토리에 들어오면 자동으로 바뀝니다.
- 모든 제작법을 데이터 레시피로 옮겨 JEI에 보이게 했습니다. 합치기·염색·잎 덮개 포함입니다.
- 모드 설정을 추가했습니다(`kit.instantPitch`).
- 최적화를 했습니다.
  - 천·지지대 렌더러의 칸별 매 프레임 계산을 틱당 한 번으로 줄였습니다.
  - 지지대 닿음 판정을 해석해로 바꿔, 긴 지지대의 가운데 교차를 놓치던 문제도 함께 고쳤습니다.
  - 쓰지 않는 코드를 정리했습니다.

### 0.3.x
- 막을 3차원 볼록 껍질로 계산합니다. 골조 표면에 닿게 덮고, 꺾이는 곳만 모따기합니다.
- 방수포·지지대를 블록 엔티티 렌더러로 그려 셰이더팩 그림자에 들어가게 했습니다.
- 천막 안이 어둡습니다. 천과 천이 지나가는 지지대 칸이 하늘빛을 줄입니다.
- 안쪽 면도 바깥 면과 같은 해 방향 음영을 받고, 투과로 감쇄됩니다. Iris 셰이더의 그림자 단계도 따로 처리했습니다.
- 천막 키트는 웅크리고 우클릭해야 회수됩니다. 설치 직후 실수로 다시 담기는 것을 막기 위해서입니다.

### 0.2.0
- 막을 처짐 없는 평면 다각형으로 바꿨습니다.
- **천막 키트**를 추가했습니다(담기·투영·Q/E 회전·부품 순서 설치).
- 지지대·노끈을 찍는 중에는 휠로 핫바가 바뀌지 않고, 지지대 길이를 ½칸씩 조절합니다.

### 0.1.0
- 시험판을 갈아엎고 새로 만든 첫 버전입니다. 재료 네 가지, 안정성 판정, 투영 후 한 번에 덮는 방수포, 입구, 잎 덮개가 들어갔습니다.
